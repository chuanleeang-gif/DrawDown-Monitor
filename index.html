For educational purposes only. Not investment advice. Quotes come from Google Finance through a Google Sheet and may be delayed up to 20 minutes. They are not sourced from all markets.
Drawdown = (current price ÷ all-time high − 1). The bar scale runs from 0% to −50%. Day high/low is the current or most recent trading session. 52-wk high/low is the trailing 52-week range; the marker shows where the current price sits inside each range.

Data source

Prices come from GOOGLEFINANCE() formulas in a Google Sheet that is published to the web as CSV. This page reads that CSV on every refresh.

  1. In Google Sheets: File › Import › upload drawdown_sheet_template.csv › Replace current sheet.
  2. File › Settings › Calculation › set recalculation to On change and every minute.
  3. Choose one way to share it, then paste that link below:
    Option A (simplest): click Share › General access › Anyone with the link › Viewer › Copy link.
    Option B: File › Share › Publish to web › pick the sheet tab › Comma-separated values (.csv) › Publish › copy the link. A "Web page" link also works; the page converts it.

Open this file in Chrome, Edge or Safari. Preview panels (such as inside a chat app or email) block outside data.

Columns read: Group, Name, Ticker, Price, Change, PrevClose, DayHigh, DayLow, High52, Low52, ATH, Calculated. Attributes used: price, change, closeyest, high, low, high52, low52, and weekly historical high for the all-time high.
